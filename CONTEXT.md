# Goose Domain Context

Этот документ содержит канонический глоссарий терминов предметной области проекта и правила их именования.

## Language

**Рабочее пространство**:
Локальный каталог файловой системы или конфигурационный файл описания рабочего пространства (`.code-workspace`), совместимый со средой разработки Cursor, в контексте которого ведутся разработка и взаимодействие с агентом.
_Avoid_: Папка проекта, рабочая директория, текущий каталог

**Проводник файлов**:
Панель иерархического отображения структуры папок и файлов текущего рабочего пространства с поддержкой навигации, базовых операций, цветовой индикации статусов версий и передачи контекста агенту.
_Avoid_: Файловый менеджер, файловое дерево, список файлов

**Контекстное меню элемента**:
Всплывающее меню по нажатию правой кнопки мыши на файле или папке, содержащее команды копирования путей («Копировать путь», «Копировать относительный путь»), базовые файловые операции и передачу элемента в контекст диалога.
_Avoid_: Меню файла, контекстник

**Статус контроля версий**:
Состояние файла или каталога в распределённой системе управления версиями Git (неотслеживаемый, изменённый, удалённый, игнорируемый правилами `.gitignore`), отображаемое цветом и буквенным индикатором в Проводнике файлов.
_Avoid_: Гит статус, состояние файла

**Область редактора**:
Центральная панель интерфейса со вкладками для просмотра и изменения содержимого файлов исходного кода на базе движка Monaco Editor.
_Avoid_: Окно редактора, центральный блок, вьюер

**Встроенное сравнение изменений**:
Режим отображения правок агента непосредственно в тексте открытого файла с подсветкой удалённых и добавленных строк, а также кнопками принятия или отклонения изменений («Принять» / «Отклонить»).
_Avoid_: Дифф, просмотр разницы, патч

**Панель агента**:
Боковая панель для ведения диалога с интеллектуальным помощником и отображения хода выполнения задач.
_Avoid_: Окно чата, сайдбар чата, консоль

**Список недавних рабочих пространств**:
Перечень ранее открывавшихся каталогов и файлов рабочих пространств для быстрого переключения между проектами.
_Avoid_: История папок, последние проекты
