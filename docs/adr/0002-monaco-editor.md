# Использование Monaco Editor для центральной Области редактора

Для обеспечения пользовательского опыта, идентичного среде разработки Cursor, в качестве движка центральной Области редактора выбран Monaco Editor с системой управления вкладками. Движок предоставляет аутентичную подсветку синтаксиса, стандартные горячие клавиши, миникарту кода и возможность отображения сравнения изменений (Diff Editor). Выбор сделан в пользу максимального функционального соответствия Cursor вопреки небольшому увеличению размера дистрибутива приложения.
