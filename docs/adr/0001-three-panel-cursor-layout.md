# Трёхпанельный макет рабочего пространства в стиле Cursor

Для обеспечения удобства работы с кодовой базой интерфейс настольного приложения Goose переводится с монолитного окна чата на трёхпанельный макет, аналогичный среде разработки Cursor. В левой части располагается Проводник файлов для навигации по проекту, в центре — Область редактора со вкладками открытых файлов, а в правой части — Панель агента для взаимодействия с интеллектуальным помощником. Такое разделение позволяет пользователю просматривать и редактировать код без переключения во внешние программы, сохраняя постоянный доступ к диалогу с агентом.
