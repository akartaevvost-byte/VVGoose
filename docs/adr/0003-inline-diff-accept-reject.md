# Встроенное сравнение изменений кода агента с принятием и отклонением

Для полного соответствия процессу разработки в среде Cursor правки файлов, предложенные агентом, отображаются непосредственно в тексте открытого файла в Области редактора в виде встроенного сравнения изменений. Удаляемые строки подсвечиваются красным фоном, а добавляемые — зелёным. Над блоком изменений выводятся элементы управления «Принять» и «Отклонить». Это позволяет пользователю рецензировать и подтверждать изменения кода по месту без переключения контекста.
